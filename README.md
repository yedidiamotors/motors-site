# motors-site

אתר ידידיה מוטורס — מתפרסם ב-GitHub Pages בכתובת https://motors.yedidia.co.il

---

## מבנה

| נתיב | תפקיד |
|---|---|
| `index.html` | דף הבית |
| `stock/index.html` | עמוד המלאי — קורא את `data/inventory.json`, מסנן, ממיין, גלריית תמונות |
| `data/inventory.json` | **החוזה היחיד** בין מקור הנתונים לאתר. נכתב אוטומטית — אין לערוך ידנית |
| `data/inventory-template.csv` | תבנית לייבוא לגוגל שיטס |
| `scripts/sync-inventory.mjs` | מושך את הגיליון, מנרמל, כותב את ה-JSON |
| `.github/workflows/sync-inventory.yml` | מריץ את הסקריפט כל 30 דקות ומקבע שינויים |
| `CNAME` | הדומיין המותאם |

> **החלפת מקור הנתונים ל-Supabase בעתיד:** משנים רק את `scripts/sync-inventory.mjs`
> כך שיקרא מ-n8n/Supabase במקום מהגיליון. מבנה ה-JSON נשאר, והאתר לא משתנה בכלל.

## הבק אופיס — גיליון גוגל

הגיליון **הוא** הבק אופיס. מי שעורך אותו מעדכן את האתר.

### הקמה חד-פעמית

1. צור גיליון חדש, ייבא אליו את `data/inventory-template.csv` (קובץ → ייבוא).
2. **קובץ → שיתוף → פרסום באינטרנט** → בחר את הגיליון → פורמט **CSV** → פרסם.
3. העתק את הכתובת שהתקבלה (מסתיימת ב-`output=csv`).
4. ב-GitHub: **Settings → Secrets and variables → Actions → Variables → New variable**
   שם: `SHEET_CSV_URL`, ערך: הכתובת מסעיף 3.
5. **Actions → סנכרון מלאי מגוגל שיטס → Run workflow** להרצה ראשונה.

### תמונות ב-Google Drive

1. תיקייה משותפת ב-Drive, הרשאה **"כל מי שיש לו הקישור — צופה"**.
2. מעלים תמונות, מעתיקים קישור לכל אחת, מדביקים בעמודה `תמונות` מופרדים בפסיקים.
3. הסקריפט ממיר אוטומטית כל קישור Drive לכתובת שניתן להטמיע
   (`lh3.googleusercontent.com/d/<ID>=w1600`). שלושת פורמטי הקישור של Drive נתמכים.

> אם תמונה לא מופיעה — כמעט תמיד ההרשאה בתיקייה לא פתוחה לכל מי שיש לו הקישור.

## מחזור העדכון

```
עורך את הגיליון
   ↓  (עד 30 דקות, או Run workflow להרצה מיידית)
GitHub Action → sync-inventory.mjs → data/inventory.json → commit
   ↓  (דקה)
GitHub Pages בונה מחדש → האתר מציג את המלאי המעודכן
```

הרצה מקומית לבדיקה:

```bash
SHEET_CSV_URL="<כתובת ה-CSV>" node scripts/sync-inventory.mjs
```
